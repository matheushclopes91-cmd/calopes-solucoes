# Calculadora ROI — CaLopes Soluções

Ferramenta interativa para calcular faturamento deixado no ralo por não responder no WhatsApp.

## Como fazer o deploy no Netlify

1. **Fazer login no Netlify**
   - Acesse [netlify.com](https://netlify.com) e faça login

2. **Fazer deploy desta pasta**
   - Opção A: Drag & drop da pasta `calculadora-roi` direto no Netlify
   - Opção B: Conectar com GitHub e fazer deploy automático

3. **Copiar o link público**
   - Netlify gera um link tipo `https://seu-site-aleatorio.netlify.app`
   - Use esse link para compartilhar a calculadora

## Características

- ✅ Sem dependências externas (tudo em 1 arquivo HTML)
- ✅ Funciona offline
- ✅ Responsivo (desktop, mobile, tablet)
- ✅ WhatsApp integrado (seu número já configurado)
- ✅ Cálculo em tempo real

## Arquivo

- `index.html` — A calculadora completa, pronta para usar

Nenhum outro arquivo ou configuração necessária.
